# Paper 3 Simulation Outputs

Run `R/run_paper3_simulations.R` with an R environment that has the packages listed in `paper3_simulation_plan.R` available. The script writes CSV summaries and PNG figures into a timestamped folder under `results/paper3_simulation/`.

```
Rscript R/run_paper3_simulations.R
```

If any packages are missing, install them via `install.packages()` before running.
